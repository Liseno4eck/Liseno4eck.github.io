# Telegram-уведомления для сайта-поздравления

## Что делает проект

- Telegram-бот регистрирует создателя по `/start`.
- Бот выдаёт персональный код создателя.
- Секретная панель сайта открывается кодом `304056`.
- В панели можно создать уникальную ссылку поздравления.
- Ссылка хранится на сервере, а не в localStorage.
- Сервер отправляет создателю уведомления:
  - «Кто-то открыл твою эмоцию ❤️»
  - «Кто-то ввел правильную дату ❤️»
  - «Кто-то нажал(а) «Да» ❤️»
  - «Кто-то отправил(а) тебе письмо: ...»
- В панели есть выбор, должна ли кнопка «Нет» убегать.

## Важное ограничение про имя

Обычный HTML-сайт не получает имя Telegram-пользователя просто от факта открытия страницы. Поэтому сервер не должен угадывать или скрыто собирать имя.

В этой версии уведомления используют «Кто-то», если имя посетителя не передано. Если тебе нужно именно имя, добавь в начало сайта добровольное поле «Как тебя зовут?» и отправляй это значение как event_name. Не собирай скрытые персональные данные.

## Установка на Windows

1. Установи Python 3.11+.
2. Открой PowerShell в этой папке.
3. Создай окружение:
   python -m venv .venv
4. Активируй:
   .\.venv\Scripts\Activate.ps1
5. Установи библиотеки:
   pip install -r requirements.txt
6. В Telegram открой @BotFather и создай бота командой /newbot.
7. Полученный токен запиши в переменную BOT_TOKEN.
8. В BOT_USERNAME укажи username бота без @.
9. PUBLIC_BASE_URL должен быть HTTPS-адресом, по которому доступен сайт.
10. Запусти сервер:
    python server.py
11. В другом окне PowerShell запусти бота:
    python bot.py

Для локальной проверки сервер будет доступен на http://127.0.0.1:8080.
Для реального использования нужен публичный HTTPS-домен/сервер.

## Переменные Windows PowerShell

$env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
$env:BOT_USERNAME="MyGreetingBot"
$env:PUBLIC_BASE_URL="https://example.com"

python server.py

В другом окне:
$env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
python bot.py

## Как пользоваться

1. Открой сайт.
2. Нажми «🔐 Войти».
3. Telegram откроет бота.
4. Нажми Start или отправь /start.
5. Бот выдаст код создателя.
6. Вернись на сайт.
7. Введи `304056`.
8. Вставь код создателя.
9. Заполни настройки.
10. Нажми «Создать ссылку».
11. Отправь полученную ссылку нужному человеку.
12. События будут приходить в Telegram создателю.

## Безопасность

Не публикуй BOT_TOKEN. Токен даёт доступ к управлению ботом. Если токен случайно утёк, перевыпусти его через BotFather.

Для публичного сайта используй HTTPS.
